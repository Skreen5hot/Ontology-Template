# SDD

The Semantic Data Dictionary team. Its repository is `Skreen5hot/SemanticDataDictionary`,
which is public. The SDD Service takes the BFO and CCO terms it permits only from this
template's pins (its ADR-005), so a change to what `vendor/` carries is a change it consumes.

The team's code for this repository, in its own messages, is `OT`. A message from the team
names `OT`; its copy here carries this record's header, which names `EXAMPLE`, over the
team's bytes (as for `BPOTEST`, template decision 20, A8).

What the team decides, and the template does not: how the SDD Service uses the vendored
artifacts, and what it accepts or rejects in a mapping.
